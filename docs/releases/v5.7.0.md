# AI Sales OS v5.7.0

发布日期：2026-07-28

## 本次更新

- WhatsApp 号码有效性改为真实注册结果：
  - 号码格式正确只代表“可以向 WhatsApp 查询”，不再直接显示“有效”。
  - WhatsApp 明确返回已注册才显示“有效”。
  - WhatsApp 明确返回未注册才显示“无效”。
  - 账号未连接、断网、超时或查询异常显示“待检测 / 待重试”，不会误判为无效。
- 新表导入后自动检测：
  - Excel / CSV 导入写入完成后，格式可查询的号码自动进入持久检测队列。
  - 队列使用任一已连接 WhatsApp 账号执行只读查询，并以固定间隔限速。
  - 切换板块或重启程序不会丢失检测任务。
  - 修改客户电话号码后会清除旧号码结论并重新排队，旧查询结果不能覆盖新号码。
- 客户列表状态更清楚：
  - “WhatsApp 状态”统一展示待检测、检测中、有效、无效、待重试、格式风险或无号码。
  - 检测结果在客户列表中实时更新。
- 自动化发送增加最后一道核验：
  - WhatsApp 任务发送前再次向 WhatsApp 查询目标号码。
  - 明确未注册时阻止发送并记录原因。
  - 查询临时失败只记录待重试，不伪造无效结论。

## 验证与数据安全

- Release 构建、原生冒烟、Bridge 协议、导入排队、已注册/未注册、未连接、异常退避和客户列表状态回归均需通过后发布。
- 安装与自动更新继续创建或修复桌面快捷方式。
- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp/邮箱账号、API 配置、客户、消息、知识库、自动化或报告数据。
- 本版本只发布 Windows 中文安装包与 Velopack 自动更新资产；macOS 发布继续暂停。
