# AI Sales OS v5.15.0

## 新电脑 Gmail 与 WhatsApp 网络自适应

- Gmail、其他 IMAP / SMTP 邮箱和 WhatsApp 首次连接会自动继承 Windows 当前系统代理，以及 `WAFLOW_PROXY_URL`、`HTTPS_PROXY`、`ALL_PROXY`、`HTTP_PROXY` 环境代理。
- 邮箱 IMAP、SMTP、后台同步、手动同步和连接测试共用同一条网络选择逻辑；代理失败时自动回退直连，不要求删除或重新添加账号。
- WhatsApp 桥接新增 HTTP、HTTPS、SOCKS5 代理支持；系统代理无法生成真实二维码时会自动切换直连并重新连接。
- 邮件临时断线改为页面内状态提示，不再弹阻塞式错误窗口；本地已同步邮件始终可继续查看。
- 连接失败会区分超时、DNS、TLS/证书和网络阻断，并提供可执行中文说明；代理账号密码不会显示在界面或日志中。
- 新增代理凭据脱敏、HTTP/SOCKS 路由、代理到直连回退和新电脑连接契约测试。

## WhatsApp 最新消息翻译修复

- “翻译最近消息”固定选择当前会话最新 30 条可翻译文本，按时间顺序显示完成后自动回到最新消息，不再把数日前的缓存内容误当成最近消息。
- 连续点击会重新核对当前最新消息窗口；已有译文复用本机缓存，新到达或内容变化的消息会继续翻译，按钮不会在第二次操作后失效。
- 语言识别和翻译运行使用独立取消状态，切换会话、后台刷新或一次失败不会锁住后续操作。
- AI 返回的结构化 JSON 偶发异常时，系统优先沿用已验证的会话语言，并自动把翻译批次拆小重试；首次会话也有本地语言识别兜底。
- 新增最新 30 条选择、重复点击、新消息刷新、语言识别格式异常和翻译批次拆分恢复回归测试。

## 数据与更新安全

- 升级不会覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或更新后继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- 本版本只发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不直接修改本机正式程序；macOS 发布继续暂停。
