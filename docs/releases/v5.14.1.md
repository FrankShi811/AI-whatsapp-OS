# AI Sales OS v5.14.1

## Dashboard 未读消息行动简报

- WhatsApp Inbox 与邮件 Inbox 的未读客户消息合并为一份行动清单，按要点展示客户、主题、摘要、建议下一步、优先级和来源。
- 来源仅显示“WhatsApp”或“邮件”，删除重复的空状态说明、WhatsApp/邮件数量标签和“Dashboard 模型未配置”提示。
- 点击行动项可直接进入对应 Inbox；生成摘要不会自动回复、发送消息或将原消息标为已读。

## 自动模型与后台更新

- Dashboard 不再提供或依赖人工板块模型配置，始终从当前 API 实际返回的模型目录中自动选择最低配置模型和最低已声明推理深度。
- 程序启动、WhatsApp 新消息、邮件新消息和已读状态变化时，后台自动合并并刷新简报；短时间重复事件会防抖处理。
- 未读内容没有变化时复用本地缓存；没有未读消息时不调用 API，不消耗 Token。
- 后台复用现有 WhatsApp 与邮箱同步链路，不额外建立账号连接，不阻塞当前页面。

## 可用性与验证

- 统一行动清单已完成亮色、暗色及约 1100px 窄窗口原生视觉验收。
- 新增原生回归测试，覆盖跨渠道合并、来源标注、静默最低模型选择、最低推理深度、缓存、防抖后台刷新和零未读免调用。
- Dashboard 新手引导同步更新，说明最低模型、后台同步、缓存和不会自动发送的安全边界。

## 数据与发布边界

- 不覆盖客户、消息原文、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或自动更新继续创建或修复桌面快捷方式，并仅保留当前、待更新版本及最近三个回滚版本的更新缓存。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
