# AI Sales OS v5.10.2

## Inbox 异步加载与界面响应修复

- WhatsApp 与邮件 Inbox 的账号、客户、会话、联系人和消息数据在后台读取、整理，界面只接收一次完整快照，避免 SQLite 与大量对象构建占用 WPF 主线程。
- 会话和消息列表采用单次批量替换；切换板块时先显示页面，再异步加载数据。
- 隐藏的 Inbox 不再因后台同步重建列表；新消息先更新全局未读气泡，进入相应页面时再加载最新内容。
- 短时间重复到达的同步和分析事件会合并，不再并行触发多个整页刷新。

## 邮件同步稳定性

- 手动“同步收件箱”复用并唤醒现有后台 IMAP 会话，不再为同一账号并发建立第二条连接。
- IMAP 暂时断开时由后台自动重连；界面会说明无需删除或重新添加邮箱账号。
- 正常同步完成后使用非阻塞状态反馈，不再弹出成功对话框打断操作。

## 验证

- 新增隐藏页面、后台读取、事件防抖、批量更新以及单 IMAP 会话回归门禁。
- 执行 Release 构建、原生冒烟、完整回归、隔离安装/启动/卸载、桌面快捷方式和生产数据库哈希验证。
- 亮色与暗色主题、键盘焦点、缩放、禁用状态和 WCAG AA 4.5:1 自动门禁保持执行。

## 数据与发布边界

- 升级不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化或报告数据。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产；安装或更新继续创建或修复桌面快捷方式。
- 不直接覆盖、关闭、重启或安装本机正式程序；macOS 正式发布继续暂停。
