# AI Sales OS v4.2.5

## WhatsApp 多账号已读气泡持久化

- 修复个人 WhatsApp 账号点开会话后，未读气泡只在当前页面消失、切换到其他板块再返回时重新出现的问题。
- 根因是已读写入固定查询默认 `primary` 账号，无法找到实际属于 `personal_*` 账号的会话，因此数据库中的未读数和已读游标没有更新。
- 已读操作现在按全局唯一会话 ID 直接读取和更新记录，在同一串行写入锁内将未读数清零并单向推进已读游标。
- 后台联系人、聊天及历史同步仍不能用旧快照覆盖用户已经完成的已读操作。

## 验证与发布边界

- 新增非 `primary` WhatsApp 账号已读持久化回归，覆盖离开并重新进入 WhatsApp Inbox 后未读气泡保持清除。
- 继续执行 Bridge 冒烟、桌面原生完整回归、中文安装器冒烟与 Velopack 自动更新清单校验。
- 保留 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp 会话、媒体、API 与邮件配置。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产。
- 不覆盖、关闭、重启或安装本机 `D:\AI Sales OS\aisalesos.exe`；macOS 构建继续暂停。
