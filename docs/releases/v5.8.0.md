# AI Sales OS v5.8.0

发布日期：2026-07-28

## 本次更新

- 程序启动后持续监控 GitHub Release：
  - 启动时立即检查，运行期间每 2 分钟再次检查。
  - 发现新版本后在后台自动下载并校验。
  - 下载完成后在左下角明确提示“点击更新并重启”。
  - 只有用户点击并确认后才关闭程序、安装更新并自动重启。
  - 临时检查失败会在后续周期自动重试，不影响其他功能继续运行。
- 客户列表新增一级品类偏好：
  - 从导入表格的“一级品类偏好”及兼容表头实时读取。
  - 作为固定列展示，并可单独筛选、搜索和排序。
  - 固定列不会再在右侧动态维度区重复出现。
- 自动化群发新增一级品类偏好：
  - 发送客户列表固定展示该维度。
  - 可与搜索、等级、阶段组合筛选。
  - “全选当前可发送”只选择当前筛选结果中的可发送客户。

## 验证与数据安全

- Release 构建、原生冒烟、完整回归、更新监控契约、品类表头兼容、客户列表与群发筛选契约均需通过后发布。
- 安装与自动更新继续创建或修复桌面快捷方式。
- 升级不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、消息、WhatsApp/邮箱账号、API 配置、知识库、自动化或报告数据。
- 本版本只发布 Windows 中文安装包与 Velopack 自动更新资产；macOS 发布继续暂停。
