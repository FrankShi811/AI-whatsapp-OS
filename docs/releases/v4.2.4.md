# AI Sales OS v4.2.4

## WhatsApp 入站文本恢复

- 修复手机端可见的普通文字在桌面端显示为“媒体消息”的问题。
- 密文占位通知会显示为“正在从手机恢复消息内容”；手机补回正文后，按原消息 ID 原位更新数据库和当前会话气泡。
- 迟到的空占位、协议控制消息或无实际状态的更新不能覆盖已恢复正文，也不会重复增加未读数或触发业务处理。
- 补齐临时消息、编辑消息、手机端发送封装及联系人、位置、投票、回应、活动等消息类型的解析与标签。

## Windows 自动更新日志编码

- 修复 Velopack 在 Windows 打包时按默认代码页读取无 BOM 中文说明，导致 `releases.win.json` 更新日志乱码的问题。
- 打包时生成带 BOM 的 UTF-8 更新说明，确保程序左下角版本中心正确显示简体中文。
- 发布前自动验证当前版本更新说明包含正确标题且不存在 Unicode 替换字符；不符合要求时阻断 Release。

## 验证与发布边界

- Bridge 正文解析、占位恢复、迟到占位防回退、单次业务处理、内嵌 EXE 冒烟、完整核心回归与中文安装器冒烟均纳入验证。
- 保留 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp 会话、媒体、API 与邮件配置。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产。
- 不覆盖、关闭、重启或安装本机 `D:\AI Sales OS\aisalesos.exe`；macOS 构建继续暂停。
