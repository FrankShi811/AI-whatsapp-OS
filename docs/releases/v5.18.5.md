# AI Sales OS v5.18.5

## 商机智能实时进度统一修复

- 商机智能顶部操作固定只显示“使用 XX 模型分析”，不再把失败客户数、未完成客户数或重试状态塞入按钮文案。
- 批量分析运行期间以后台任务的实时快照作为唯一进度来源；切换板块再返回时立即恢复当前任务的已完成数与总数，数据库累计分析数和历史运行记录不再覆盖活动任务。
- 看板“AI 分析覆盖”与商机智能共用同一实时快照。例如当前任务为 `290 / 598` 时，两处都会同步显示 `290 / 598` 和对应百分比。
- 断点续跑、失败客户重试和安全停止能力保持不变，但这些执行状态不再改变用户看到的模型操作名称。
- 新增共享进度事件、返回页面恢复、看板实时同步、固定按钮文案及无障碍实时状态回归。

## 发布边界

- 仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 发布继续暂停。
