# AI Sales OS v5.18.3

## WhatsApp 重新扫码与连接状态修复

- 修复点击“连接 / 显示二维码”后在“连接中”“已断开”“5 秒后自动重试”之间反复横跳、始终无法生成二维码的问题。Windows 系统代理若在二维码出现前断开，会立即切换直连，不再每 5 秒重新使用同一条失败代理。
- 连接、断开和退出账号改为同一账号串行执行。点击断开或退出会立即取消仍在等待二维码的连接任务，并用连接代次阻止旧定时器和迟到事件重新拉起连接。
- 退出账号即使遇到远端登出超时，也会停止本程序自己的桥接子进程并清空该账号的本机会话。重新扫码使用的本机加密凭据继续安全保存在 Windows 凭据管理器，确保新配对在程序重启后仍可读取。
- 新增按 Windows 用户生效的单实例保护。后续重复启动 AI Sales OS 只会唤醒已有窗口，不再同时启动两套 WhatsApp 桥接进程争用同一会话。
- WhatsApp 页面在连接操作期间禁用冲突按钮，并明确显示“连接已停止”或“本机登录会话已清除”；退出后可直接点击“连接 / 显示二维码”生成新二维码。
- 新增代理失败切换、手动断开不复活、本机会话清除和重新扫码生命周期回归。

## 发布边界

- 仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 发布继续暂停。
