# AI Sales OS v5.3.2

## WhatsApp 全局未读气泡与跨账号身份纠错

- 修复会话已有本地读游标后，实时新消息被防旧快照逻辑错误恢复为 0 未读的问题。
- 真正的新来信会在消息持久化后立即更新全部账号的 WhatsApp Inbox 导航气泡；同步事件和每 5 秒轻量校准负责补偿任何短暂遗漏。
- 用户停留在 Dashboard、商机智能、客户列表或其他板块时仍能看到新消息；进入对应会话后才清除该会话未读数。
- 旧历史、晚到事件和过期会话快照继续受单调读游标保护，不能恢复已看过的气泡。
- 会话名称优先使用 WhatsApp 联系人、保存名称、推送昵称或企业认证名称；CRM 客户名只作为关联信息展示，不再覆盖 WhatsApp 原生名称。
- 当会话号码属于另一个已登录 WhatsApp 账号时，系统将其识别为本机账号互发，不再误绑定外部 CRM 客户，也不会触发 Customer Brain 或 Agent 自动处理。
- 升级启动时会增量解除此类错误身份链接并清除会话、消息上的 CRM 引用，保留审计记录，不删除客户或消息。

## 验证与数据安全

- 新增已读游标后的实时来信、全局未读汇总、进入会话清零、旧快照防回退、WhatsApp 原生名称保留、双账号互发隔离和错误绑定修复回归。
- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户资料、WhatsApp 账号、消息、API 配置、邮件账号、自动化任务、Windows 凭据或知识库数据。
- 本版本仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序。
- macOS 构建、安装包与 Release 资产继续暂停。
