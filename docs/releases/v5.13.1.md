# AI Sales OS v5.13.1

## 商机队列分页与群发受众区紧凑化

- 多渠道自动化触达将“全选当前可发送”和“清空选择”并入等级、阶段、一级品类筛选行，释放客户表格的纵向空间。
- 商机智能的商机队列新增：
  - 每页 10、30、50 条切换，默认每页 30 条。
  - 当前显示范围、商机总数和页码提示。
  - 上一页、下一页按钮及首尾页禁用状态。
- 搜索、等级筛选或每页数量变化后自动回到第一页；普通刷新会保留当前有效页码。
- 分页只影响列表展示，不改变“分析全部 / 重试失败”的全量分析范围，也不会修改客户资料、AI 分数、阶段或 Customer Brain。
- 商机智能与自动化群发使用手册、原生回归门禁已同步更新。

## 升级与发布边界

- 升级不覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或自动更新继续创建或修复桌面快捷方式。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
