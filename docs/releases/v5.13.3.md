# AI Sales OS v5.13.3

## WhatsApp 自聊身份与联系人名称修复

- 本机已登录 WhatsApp 账号的号码现在包括当前账号自身和其他已登录账号。
- 给自己发消息或在本机多个账号之间互发时，不再使用 CRM 电话匹配或旧人工绑定识别客户。
- 本机账号名称优先于旧会话名称、联系人快照与消息 pushName；示例中的 `+8613073611720` 会恢复显示为 `Frank`，不会再错误显示为 `Azita`。
- 启动修复会自动解除本机账号号码上残留的客户身份绑定，并清除会话与消息的错误客户关联。
- 非本机账号号码仍遵循既有规则：
  - 电话唯一匹配客户列表时，显示 CRM 客户名。
  - 电话没有唯一匹配时，显示 WhatsApp 同步的原生备注名。
- 新增同账号自聊、跨账号互发、旧绑定解除、名称恢复和防止重新关联的原生回归测试。

## 数据与发布边界

- 不删除 Azita 等 CRM 客户记录，也不删除 WhatsApp 聊天原文。
- 不覆盖客户、原始字段、WhatsApp/邮箱账号、API Key、知识库、自动化、报告或本地数据工作区。
- Windows 安装或自动更新继续创建或修复桌面快捷方式。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
