# AI Sales OS v5.6.0

发布日期：2026-07-28

## 本次更新

- 精简商机智能队列：
  - 取消“公司”列，优先展示客户、市场、等级、AI 分数、阶段和分析状态。
  - 公司资料仍完整保存在 CRM、Customer Brain 与客户报告中。
- 调整 Dashboard 今日行动简报：
  - 不再生成或统计“身份待确认”任务。
  - WhatsApp / 邮件 Inbox 中尚未匹配客户列表的联系人，需先在右侧栏人工创建并同步客户，之后才参与跨板块数据联动。
- 优化客户列表：
  - 每页数量固定为单行“10/30/50 条/页”。
  - 横向与纵向滚动条使用亮暗主题语义样式，修复右侧滚动区域顶部突兀留白。
- 新增商机智能独立 AI 路由：
  - 可在 API 对接中单独选择 Provider、模型和接口声明支持的推理深度。
  - 单客分析、WhatsApp 新回复后台分析和批量分析统一走商机智能板块配置。
  - 旧用户未配置该板块时自动继承全域模型，不影响现有 API Key 与其他板块设置。

## 验证与数据安全

- Release 构建、原生冒烟、今日行动简报、分页布局、主题滚动条和独立 AI 路由回归均需通过后发布。
- 安装与自动更新继续创建或修复桌面快捷方式。
- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp/邮箱账号、API 配置、客户、消息、知识库、自动化或报告数据。
- 本版本只发布 Windows 中文安装包与 Velopack 自动更新资产；macOS 发布继续暂停。
