# AI Sales OS v5.11.0

## 本地数据工作区可迁移

- “设置”中的本地数据工作区新增当前路径、占用空间和磁盘剩余空间。
- 可点击“打开位置”查看真实目录，或点击“迁移工作区”选择 D、E 等其他本机固定磁盘。
- 迁移覆盖 SQLite 数据库、客户与 AI 结果、WhatsApp 加密会话与媒体、邮件索引、知识库原件、自动化、报告和本地运行资料。
- API Key、邮箱密码和 WhatsApp 会话加密密钥继续由 Windows 凭据管理器保护，不写入迁移目录。

## 可恢复迁移流程

1. 退出旧进程并拒绝仍被其他 AI Sales OS 进程占用的工作区。
2. 把源工作区复制到目标磁盘的临时目录。
3. 逐文件校验 SHA-256，并执行 SQLite `integrity_check` 与 `foreign_key_check`。
4. 全部通过后原子写入工作区位置索引，再从新位置启动。
5. 新工作区完成应用初始化后才清理旧位置。
6. 启动失败时恢复旧位置；检测到旧位置出现新变化时保留原数据并提示用户。

网络共享、移动盘、非空目录，以及新旧工作区互相嵌套的路径不会被用于正式工作区。

## 升级与发布边界

- 升级不覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告或 SQLite 数据。
- Windows 安装或更新继续创建或修复桌面快捷方式。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
