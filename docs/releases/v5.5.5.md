# AI Sales OS v5.5.5

## 客户列表紧凑布局与分页

- 删除客户列表搜索区第二行的精细筛选内容，让客户表格整体上移。
- Buyer Nickname 与客户姓名合并进同一个“客户”列；原始字段继续保存在客户档案中，不会丢失。
- 原表维度下拉用于控制动态列显示范围，减少不必要的横向滚动。
- 新增每页 10、30、50 位客户选择，以及上一页、下一页、页码和当前显示范围。
- 搜索、等级、阶段与排序完成后再分页；“全选本页”支持跨页累计已选客户。
- 客户列表使用手册已同步更新。

本版本继续保护本地 SQLite 客户数据、原始字段、消息、WhatsApp/邮箱账号、API 配置、知识库、自动化和报告；Windows 安装及自动更新继续创建或修复桌面快捷方式，macOS 发布保持暂停。
