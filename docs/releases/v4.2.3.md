# AI Sales OS v4.2.3

## WhatsApp 入站文本恢复修复

- 修复手机端可见的普通文字在桌面端显示为“媒体消息”的问题。
- WhatsApp 桥接层收到密文占位通知时，准确显示“正在从手机恢复消息内容”，不再误判为媒体。
- 手机补回真实正文后，按原消息 ID 原位更新数据库和当前会话气泡，不新增重复消息、不重复增加未读数。
- 迟到的空占位或协议控制消息不能覆盖已经恢复的文字、附件、引用和送达状态。
- 补齐临时消息、编辑消息、手机端发送封装及联系人、位置、投票、回应、活动等消息类型的解析与标签。
- 纯协议控制消息不再进入客户会话；无实际状态的 `messages.update` 不再被误记为发送失败。

## 验证与发布边界

- 新增桥接正文解析、占位恢复、迟到占位防回退和单次业务处理回归。
- 保留 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp 会话、媒体、API 与邮件配置。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产。
- 不覆盖、关闭、重启或安装本机 `D:\AI Sales OS\aisalesos.exe`；macOS 构建继续暂停。
