# AI Sales OS v5.18.10

## 邮件附件查看与下载

- 邮件收件箱现在会同步并显示邮件附件：打开邮件即可看到附件列表（文件名与大小），点击“下载”可另存到本地。
- 此前已同步的历史邮件会在下次同步收件箱时自动补齐附件信息（仅执行一次，不会重复下载）。
- 内嵌在正文中的图片（cid 引用）不会显示为附件，避免正文插图干扰列表。
- 附件保存在本地数据目录 email-attachments 下，邮件删除不影响已下载文件；附件解析失败不会影响邮件正文同步。

## 发布边界

- 仅发布 Windows x64 简体中文安装包和 Velopack 自动更新资产。
- 不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新后继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本和最近 3 个回滚版本。
- macOS 构建继续暂停。
