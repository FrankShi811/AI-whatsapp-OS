# AI Sales OS v5.18.4

## WhatsApp 强制重新扫码与会话清理修复

- 修复手机端已经从“已关联设备”剔除本机后，AI Sales OS 点击“退出账号”再点击“连接 / 显示二维码”仍在连接状态之间反复横跳、无法重新扫码的问题。
- 退出账号现在无论 WhatsApp 远端登出返回成功、超时还是异常，都会先强制结束该账号旧 Bridge 子进程，再清空且只清空该账号的本机会话。其他 WhatsApp 账号、客户、消息和业务数据保持不变。
- 旧连接在退出后迟到的凭据更新不再允许重新写回已清除会话，避免下一次连接误把残留凭据当作仍有效的旧设备并跳过二维码配对。
- 如果手机端已提前解除关联，首次点击“连接 / 显示二维码”收到 `logged_out` 后会在同一次点击内自动重置旧会话、重启 Bridge 并继续等待真实二维码，不要求用户反复点击退出和连接。
- 新账号配对使用 WhatsApp Web 当前接受的 Windows Chrome 客户端身份和实时协议版本；扫码成功后自动升级为 Desktop 历史同步身份，兼顾二维码可用性与离线历史补齐。
- 新增成功退出后精确账号清理、兄弟账号保留、迟到凭据拦截、远端解除关联同次点击恢复，以及真实 WhatsApp 二维码数据生成生命周期回归。

## 发布边界

- 仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 发布继续暂停。
