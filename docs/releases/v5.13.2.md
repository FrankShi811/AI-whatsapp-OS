# AI Sales OS v5.13.2

## 更新缓存自动清理与三版本回滚保留

- 每次更新包下载完成及安装后首次启动，自动整理 AI Sales OS 更新缓存：
  - 始终保留当前已安装版本。
  - 始终保留已经下载、等待安装的更高版本。
  - 额外保留最近 3 个旧版本作为回滚缓存。
- 便携版下载的正式安装包只保留最近 3 个版本目录；Velopack 临时目录只删除超过 24 小时的旧缓存。
- Windows 发布脚本在每次构建结束后执行同一保留策略，自动裁剪本地全量包、增量包及相应更新清单，防止发布缓存无限增长。
- 清理范围严格限定为标准命名的 AI Sales OS 更新包、Velopack 专用临时目录和便携版安装包缓存；不认识的文件与更新元数据继续保留。
- 新增回归用例，验证待安装新版本、当前版本、3 个回滚版本、Velopack 锁文件及无关包不会被误删。

## 数据与发布边界

- 不删除或迁移客户数据库、WhatsApp 账号与会话、邮件账号与历史、API 配置、知识库、自动化任务、报告或本地数据工作区。
- Windows 安装或自动更新继续创建或修复桌面快捷方式。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
