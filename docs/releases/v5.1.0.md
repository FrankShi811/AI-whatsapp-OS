# AI Sales OS v5.1.0

## 全账号消息常驻同步

- 程序启动后自动扫描全部 WhatsApp 账号；只有已成功登录、保存有效加密会话且仍有关联号码的账号才会在后台恢复连接，不会为从未登录的空账号弹出二维码。
- 每个 WhatsApp 账号使用独立桥接进程和连接状态；网络或桥接进程中断后，应用级守护每 15 秒检查并重建连接，连接成功后立即补拉历史，并每 5 分钟执行一次增量补偿同步。
- 用户主动点击“断开”或“退出账号”会在本次程序运行期间暂停该账号自动重连，避免后台违背人工操作；重新手动连接或下次启动后按保存的登录状态恢复。
- WhatsApp 消息同步不再依赖当前是否打开 WhatsApp Inbox，所有账号的实时事件仍会写入同一份本地 SQLite 客户与会话数据。

## 邮件实时收取与自动恢复

- 所有已配置且凭据仍存在于 Windows 凭据管理器的邮箱账号，在程序运行期间分别建立 IMAP 后台会话，不再只在点击“同步收件箱”时短暂连接。
- 支持 IMAP IDLE 的 Gmail、Yahoo、iCloud 和兼容企业邮箱会保持实时等待；服务商不支持 IDLE 时每 30 秒执行安全 NOOP 轮询。
- 每次连接先补拉最近 500 封邮件，收到服务器新邮件通知后增量检查最近 150 封；按服务器 UID / Message-ID 去重，不重复创建邮件或未读数。
- 网络、认证或服务端中断不会终止全局同步；账号按 5 秒、10 秒逐步退避，最长 5 分钟后继续重试，并把最新连接状态保存到本地。

## 全局未读气泡与已读一致性

- 左侧 WhatsApp Inbox 和邮件 Inbox 增加高对比未读数量气泡，分别汇总全部账号；超过 99 条显示 `99+`，悬停可查看精确数量。
- 用户在 Dashboard、商机智能、客户列表、自动化群发、知识库或客户智能分析时，新 WhatsApp 和邮件消息仍会实时更新侧栏气泡。
- 只有 Inbox 当前可见且用户实际进入具体会话时才清除未读；隐藏页面的后台刷新不会误标已读。
- WhatsApp 与邮件均保存单调递增的已读游标；晚到的旧历史、过期同步结果或页面重载不能恢复已经清除的气泡，晚于游标的真实新消息仍会正确递增。
- 气泡在浅色和深色主题下均使用独立语义颜色，并通过 WCAG AA 4.5:1 对比度门槛。

## 验证、数据与发布边界

- 新增邮件已读游标、旧快照防回退、真正新邮件递增、双渠道全局汇总、全账号连接守护、IMAP IDLE/轮询和侧栏 UI 契约回归。
- 数据库只在现有邮件会话 JSON 中兼容增加已读时间，不删除或覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、WhatsApp 账号、邮件账号、API 配置、自动化任务、知识库和历史消息。
- 安装与更新继续创建或修复桌面及开始菜单快捷方式。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序；macOS 构建继续暂停。
