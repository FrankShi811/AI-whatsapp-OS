# AI Sales OS v5.5.1

发布日期：2026-07-28

## 商机智能批量分析稳定性修复

- 修复 DeepSeek 思考模型在 Lead Intelligence 批量分析中大量出现“执行失败 / AI 格式异常”的问题：结构化输出预算由 2200 提升至 16384 Token，默认请求超时由 45 秒延长至 90 秒，避免思考内容耗尽预算后没有最终 JSON。
- 正确识别 `finish_reason=length`、已经生成 `reasoning_content` 但最终 `content` 为空，以及 JSON 模式偶发空内容；结构修复增加到三轮并携带上一轮输出和具体校验提示。
- 网络中断、超时、429 限流、5xx 与畸形 Provider 响应新增有限退避重试；鉴权或配置错误会立即停止，不再对后续客户重复发起必然失败的请求。
- 未完成批量任务会把先前失败客户重新放回队列并优先重试；已完成任务再次执行时只重试失败客户，不重复分析成功客户，减少不必要的 Token 消耗。
- 连续 3 位客户在完整重试后仍失败时，系统自动暂停批量任务并保存剩余队列；用户可稍后继续，不会在 Provider 系统性异常时把整批客户全部跑成失败。
- 新增思考模型空最终答案、输出截断、瞬时 Provider 故障、三轮结构修复、失败客户恢复与批量熔断回归。

## 数据与发布边界

- 升级不覆盖客户、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告或 `%LOCALAPPDATA%\WAFlow\waflow.db`。
- Windows 安装或自动更新后会继续创建或修复桌面快捷方式和开始菜单快捷方式。
- 本版本仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产；不会覆盖、关闭、重启或安装本机正式程序。
- macOS 发布继续暂停。
