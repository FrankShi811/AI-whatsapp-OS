# AI Sales OS v5.16.1

## 本地数据工作区迁移重启修复

- 修复点击“迁移工作区”并重启后仍继续显示 C 盘原位置的问题：迁移重启会对常驻 WhatsApp、邮件、自动化、号码校验与更新服务执行有上限的安全收尾，避免后台服务长期阻止旧进程退出。
- 无论某个后台服务是否在时限内完成收尾，程序都会在退出前释放工作区租约；迁移辅助进程确认旧实例和数据库句柄已经释放后，才开始复制、校验与切换路径。
- 迁移辅助进程若发现原程序仍未退出，只报告可重试状态并停止，不再变成第二个正式程序窗口；失败迁移继续使用原工作区，绝不显示虚假的新路径。
- 选择 AI Sales OS 安装目录作为迁移目标时，数据会自动放到该磁盘独立的 `AI Sales OS Data` 目录，避免把客户数据、消息、媒体和索引混入自动更新安装目录。
- 迁移继续使用先复制后校验策略：验证全部文件哈希、SQLite 完整性、外键和内部文件路径后才写入工作区定位文件；新位置成功启动后再清理原位置，失败则保留并回退原数据。
- 完整原生回归实际验证活动数据库拒绝迁移、客户与 SQLite 数据保留、WhatsApp 会话和媒体复制、内部路径改写、成功切换及原位置安全清理。

## 发布边界

- 本版本仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式；更新缓存继续仅保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 继续暂停。
