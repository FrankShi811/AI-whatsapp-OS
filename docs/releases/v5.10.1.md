# AI Sales OS v5.10.1

## 分板块模型保存一致性

- 修复设置页底部“知识库”和“客户智能分析”等独立模型选择保存后，重新打开可能回到旧模型的问题。
- Provider、模型和推理深度在选择时立即提交；点击“保存并应用”前，系统还会强制提交全部板块控件的实时值。
- 保存完成后，系统立即从 SQLite 回读并逐一核验 7 个板块。任一项不一致时窗口保持打开，并明确提示受影响板块，不再静默关闭。

- 亮色与暗色主题、键盘焦点、缩放、禁用状态和 WCAG AA 4.5:1 自动门禁保持通过。

## 数据与发布边界

- 升级不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化或报告数据。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产；安装或更新继续创建或修复桌面快捷方式。
