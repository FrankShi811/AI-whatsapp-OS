# AI Sales OS v5.18.15

## 修复群聊新消息与历史不同步

- 修复 WhatsApp 群聊消息不同步的问题：网页模式连接的账号此前会跳过群聊发现、离线消息补拉与历史请求，导致手机上有新消息的群聊在 OS 上完全看不到；本版恢复群聊清单同步、按需历史请求与离线补拉。
- 修复群聊消息因缺少群加密密钥（发送方密钥）而被静默丢弃的问题：无法解密的群消息现在会显示占位提示，群会话立即出现，密钥到达后后续消息正常解密显示。
- “同步联系人与历史”现在会同步全部参与群聊的清单与可用的历史消息。

## 说明

- 网页模式账号的历史消息受 WhatsApp 加密限制：新配对设备无法解密配对前错过的群消息内容（显示占位提示），配对后收到的新消息可正常解密显示。
- 更新后请点一次“同步联系人与历史”拉取群聊清单。

## 发布边界

- 仅发布 Windows x64 简体中文安装包和 Velopack 自动更新资产。
- 不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新后继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本和最近 3 个回滚版本。
- macOS 构建继续暂停。
