# AI Sales OS v5.18.2

## Tavily 调查参数兼容修复

- 修复 Tavily 搜索密钥已安全保存、连接测试正常，但对国家字段为中文或其他本地化文本的客户发起正式调查时返回 HTTP 400 的问题。
- Tavily 正式调查不再把未经验证的客户国家文本写入只接受英文枚举的可选参数。客户国家仍保留在本地主体匹配和证据核验中，不会删除或覆盖客户列表资料。
- 搜索服务的未配置、网络不可用、额度限制与请求参数被拒绝现在分别显示真实原因和下一步操作，不再把 Provider 请求失败误报为“当前未配置可用搜索服务”。
- 升级后无需重新输入 Tavily 密钥。原失败任务继续保留在本地审计记录中，选择同一客户再次点击“开始调查”即可创建新任务。
- Customer Brain、客户智能分析和其他板块继续读取同一客户 ID 与有效调查事实；本修复不改变客户主数据、消息、报告、设置或事实审核边界。
- 新增本地化国家参数、Tavily HTTP 400 错误分类和错误文案回归。本版本包含 v5.18.1 的 WhatsApp 周末离线历史完整恢复。

## 发布边界

- 仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 发布继续暂停。
