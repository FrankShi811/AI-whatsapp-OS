# AI Sales OS v5.18.1

## WhatsApp 周末离线历史完整恢复

- 修复程序关闭数日后，手机 WhatsApp 已收到周末离线消息，但 AI Sales OS 会话仍停留在旧日期的问题。
- WhatsApp 新配对改为 Desktop 完整历史身份，并在首次连接时接收个人会话、群聊和消息历史；连接后主动发现账号已参与的群聊。
- 启动、断线重连与“同步联系人与历史”按每个会话最后一条本地消息的独立游标核对缺口，不再只刷新本机缓存或依赖单一全局时间。
- 历史请求统一发送毫秒时间戳，避免秒/毫秒单位错误导致 WhatsApp 静默忽略补拉请求。
- 不再把 `receivedPendingNotifications` 当成实际消息恢复成功；只有数据库确实新增消息才显示恢复数量，超时或无新增时给出真实状态。
- v5.17.4 或更早版本建立的配对属于旧 Web 历史模式，无法在原会话上补发完整历史。安装 v5.18.1 后按页面提示退出账号并重新扫码一次；新版会保存 Desktop 历史模式标记，之后无需反复扫码。
- 新增历史游标、群聊发现、配对模式、首次连接、无新增与恢复成功回归测试。
- 包含 v5.18.0 的客户外部调查、公开商业信息证据、Customer Brain 身份隔离和客户数据统一能力。

## 发布与数据边界

- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产；不关闭、重启、安装或覆盖本机正式程序。
- 安装和更新继续创建或修复桌面快捷方式；只清理可识别的更新缓存，并保留当前版本、待安装新版本与最近 3 个回滚版本。
- 不覆盖本地 SQLite、WhatsApp 会话、API 配置、邮箱账号、客户数据、知识库、报告或自动化任务。
- macOS 版本继续暂停。
