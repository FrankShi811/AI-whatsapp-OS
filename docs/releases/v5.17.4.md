# AI Sales OS v5.17.4

## 商机批量进度返回页恢复

- 修复商机智能批量分析运行期间切换到其他板块再返回时，页面短暂显示旧持久化队列和错误待继续数量的问题；返回页面会立即恢复同一后台任务的实时进度快照。
- 正在运行任务的总数、已完成、成功、失败和当前客户成为唯一显示来源；数据库累计完成数和上一次保存队列不能再覆盖活动任务状态。
- 页面异步读取 AI 路由和保存队列前后都会复核任务状态，避免读取过程中任务刚好推进产生竞态；停止分析按钮也会保持真实可用状态。
- 新增切换板块后恢复实时快照、迟到刷新不覆盖任务状态和安全停止状态回归。

## 发布与数据边界

- 本版本仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不关闭、重启、安装或覆盖本机正式程序。
- 升级不覆盖客户、原始字段、商机分析、WhatsApp 或邮件账号与消息、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- 安装或更新继续创建或修复桌面快捷方式；更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- macOS 构建继续暂停。
