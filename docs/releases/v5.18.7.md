# AI Sales OS v5.18.7

## WhatsApp 扫码后连接恢复修复

- 修复扫码验证成功后可能陷入“自动重试中”死循环的问题：新设备扫码配对成功并切换到完整历史同步模式时，若该模式连接持续失败，程序现在会在有限次重试后自动降级为普通连接模式，账号仍可正常连接并实时收发最新消息，不再无限重试。
- 降级后界面会提示“完整历史同步暂不可用，已自动降级为普通连接模式；最新消息收发不受影响”。
- 已在完整历史模式下正常工作的账号连接行为保持不变；仍可通过退出账号并重新扫码，在完整历史模式下恢复历史同步。
