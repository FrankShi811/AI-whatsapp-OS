# AI Sales OS v5.2.0

## 三种 Agent 模式现在有明确、不同的行为

- `仅建议`：只有用户点击右侧“立即生成建议”或会话输入区“AI”时才分析；生成内容显示在“最近一次 Agent 产出”，并直接填入输入框。AI 不会自动发送。
- `协作模式`：客户每次发来新的文字消息后，系统自动分析并生成草稿；草稿显示在右侧产出区，用户点击“填入输入框”后可修改并发送。AI 绝不自动发送。
- `自动回复`：客户新消息自动触发分析；只有客户身份、当前 WhatsApp 账号锁、安全边界和真实发送确认全部通过时才自动发送。高风险问题立即转人工。
- `自动关闭`：新消息继续同步和保存，但不触发 Customer Success Agent 分析。

## 模式说明与结果展示

- 模式下拉框下方新增动态说明，逐项显示“何时触发、内容生成到哪里、是否自动发送”；选择模式后仍需点击“应用”，右上角徽标代表当前已经生效的模式。
- 新增“最近一次 Agent 产出”，展示客户原话、生成回复、中文分析摘要、推荐下一步、生成时间和本轮处理详情。
- 运行状态明确区分：手动建议待确认、协作草稿待确认、自动回复等待服务端确认、自动回复已确认、转人工、阻断和失败。
- 生成内容与状态保存在本地会话 Agent 状态中；离开 WhatsApp Inbox、切换板块或重启应用后仍能回看最近一次产出。
- 新增“立即/重新生成建议”和“填入输入框”操作，用户不必再猜测底部 AI 按钮与右侧模式的关系。

## 行为修复与安全边界

- 修复协作模式此前在后台协调器中被直接跳过、收到新消息后没有自动生成草稿的问题。
- 协作模式即使识别出高风险问题，也只会创建人工接管状态，不会发送占位回复；只有用户明确开启的自动回复模式才可能按安全规则发送占位消息。
- 自动回复的最终状态继续以 WhatsApp 返回的服务端消息 ID、目标验证和状态码为依据，不把未确认发送显示为成功。
- 新增三模式触发、草稿持久化、协作不发送、自动回复待确认和界面可见产出回归。

## 数据与发布边界

- 本次只为现有会话 Agent JSON 状态增量增加最近产出字段，不删除或覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、WhatsApp/邮件账号、消息、API、自动化、凭据或知识库数据。
- 安装与更新继续创建或修复桌面及开始菜单快捷方式。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序；macOS 构建继续暂停。
