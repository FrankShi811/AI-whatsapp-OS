# AI Sales OS v5.9.0

## 统一设置、界面缩放与快捷方式自愈

- 左侧导航新增统一“设置”入口，把 AI Provider、全域或分板块模型、推理深度、Token 成本、界面缩放、主题和本地数据说明集中到同一个设置窗口；原右上角入口同步改名为“设置”。
- 新增 80%、90%、100%、110% 和 125% 五档界面缩放。低分辨率屏幕可缩小以展示更多内容，需要更大文字时可放大；比例保存在本地设置中，重启后继续生效。
- 设置窗口即时预览缩放，保存后主窗口无需重启即可应用；没有配置 AI API 时也能单独保存缩放和主题。
- 安装版每次启动都会重新创建桌面与开始菜单快捷方式，并验证真实 `.lnk` 文件；Velopack 接口没有生成链接时，使用 Windows 原生快捷方式服务兜底重建。
- 快捷方式统一指向安装目录稳定的 `current\AISalesOS.exe` 入口，避免版本目录切换后链接失效。
- 首次使用和板块引导统一改为从左侧“设置”完成配置，并增加不同分辨率的缩放建议。
- 升级不覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告或 SQLite 数据。本版本仅发布 Windows GitHub Release 与 Velopack 自动更新资产，macOS 继续暂停。
