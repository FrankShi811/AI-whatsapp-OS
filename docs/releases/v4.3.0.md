# AI Sales OS v4.3.0

## 邮件平台专属连接引导

- 重做“连接邮件账号”窗口：选择平台后立即显示准备条件、三步连接流程、字段填写说明和兼容性提示。
- Gmail 提供 Google 应用专用密码直达入口，明确说明先开启两步验证、邮箱与登录用户名填写完整地址、密码框填写 16 位应用专用密码而不是日常登录密码。
- 个人 Gmail 自 2025 年起默认开启 IMAP，不再引导用户寻找已经取消的 IMAP 开关；Google Workspace 账号会提示组织管理员策略可能限制连接。
- Yahoo Mail 与 iCloud Mail 增加各自官方应用密码入口、官方服务器说明和专属字段提示。
- Outlook.com / Microsoft 365 明确展示 OAuth2 / Modern Auth 兼容性限制，避免用户反复尝试普通密码；企业账号可按管理员提供的认证参数继续测试。
- 自定义企业邮箱列出需要向服务商或管理员索取的 IMAP、SMTP、端口、加密、用户名和客户端授权码清单。

## 自动填充与连接诊断

- 新建账号默认选择 Gmail，并自动填入 `imap.gmail.com:993`、`smtp.gmail.com:465` 与加密选项。
- 邮箱地址输入后，登录用户名默认自动同步为完整邮箱；用户仍可按特殊服务商要求单独修改。
- Gmail、Yahoo、iCloud 的应用专用密码粘贴后会自动清理空白字符，不影响 iCloud 密码中的连字符。
- Gmail、Outlook / Microsoft 365、Yahoo、iCloud 的 IMAP / SMTP 推荐参数均可一键恢复。
- 非 465 / 993 的加密连接强制使用 STARTTLS，不再在服务端缺少加密能力时降级。
- 连接失败按平台给出可执行的排查方向，并保留经过清理的底层技术信息。

## 验证与发布边界

- 新增所有支持平台引导完整性、官方 HTTPS 入口、Gmail 推荐参数、Microsoft OAuth 限制、字段自动同步、参数恢复和强制 STARTTLS 回归。
- 继续执行亮暗主题 WCAG AA、Bridge、桌面原生完整回归、中文安装器与 Velopack 自动更新清单验证。
- 密码和应用专用密码只保存到 Windows 凭据管理器；升级保留 `%LOCALAPPDATA%\WAFlow\waflow.db`、邮件账号、WhatsApp 会话、API 配置和全部客户数据。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与自动更新资产，不覆盖、关闭、重启或安装本机正式程序；macOS 构建继续暂停。
