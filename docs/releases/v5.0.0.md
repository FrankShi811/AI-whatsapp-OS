# AI Sales OS v5.0.0

## Knowledge Base 与可控 RAG

- 新增一级“知识库”工作台，支持 PDF、DOCX、TXT、Markdown、XLSX、CSV、PPTX、HTML 与常见图片资料。
- 文件经过格式和签名校验后保存不可覆盖原件与 SHA-256；每次更新创建独立版本，删除为软删除，历史原件和审计继续保留。
- 上传后依次进入解析、自动分类、结构化分块和待审核状态，只有用户明确审核启用后才可被 AI 检索。
- 图片通过当前 AI Provider 的视觉能力执行 OCR；不支持视觉或识别失败时保留原件并明确要求人工复核。
- 新增真实检索测试页，可查看命中文档、版本、章节/页码/表格行、作用域、相关度与知识块原文。

## 严格作用域、冲突与安全边界

- 知识作用域分为全局、WhatsApp 账号、客户、会话和临时任务；账号、客户、会话和任务标识由 SQLite 查询与服务层双重校验，禁止跨边界命中。
- 混合检索同时使用本地关键词和语义向量；SKU、型号、数字、容量和业务术语具有精确匹配权重。
- 已停用、已过期、未审核、已删除、高风险、提示词注入、开放冲突和当前会话已排除的知识不会进入 AI 上下文。
- 相互矛盾的政策、数字、期限或允许/禁止规则自动标记冲突并退出检索，必须由用户选择保留来源后重新审核。
- 检索知识始终作为“不可信参考数据”传给 AI，知识文档里的命令、提示词、密钥请求或角色覆盖不能改变系统规则。
- AI 未发送草稿不能自动沉淀为知识；真实互动和结果验证经验只能形成候选，且必须人工批准后才能发布。

## AI Sales OS 全链路接入

- Customer Success Agent、WhatsApp AI 建议、Lead Intelligence、Customer Brain 与客户智能分析统一接入知识检索层。
- 客户智能 Word/PDF 报告新增业务知识引用，列出标题、版本、位置、作用域、相关度与引用内容。
- WhatsApp AI 建议新增“本次建议参考”，支持查看原件、标记有用、排除当前会话和停用来源。
- 每次检索、返回知识块、AI 实际采用的知识块、真实发送、客户回复、阶段推进及人工反馈均保留审计记录。
- 今日行动简报新增待审核知识、开放冲突和候选知识任务，不使用 AI 自动修改正式知识。

## 验证、数据与发布边界

- 新增 TXT、Markdown、CSV、HTML、DOCX、PPTX、XLSX、PDF 与 OCR 解析回归。
- 新增未审核不可检索、五级作用域隔离、精确术语排序、反馈排除、停用即时失效、提示注入阻断、冲突人工处理、不可覆盖版本、软删除与重启持久化回归。
- 数据库迁移只增量创建知识文档、版本、知识块、标签、冲突、检索审计、结果反馈和候选表；保留 `%LOCALAPPDATA%\WAFlow\waflow.db`、WhatsApp 账号、邮件账号、API 配置与全部客户数据。
- 安装与更新继续创建或修复桌面及开始菜单快捷方式。
- 本版本仅通过 GitHub Release 发布 Windows 中文安装包与 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序；macOS 构建继续暂停。
