# AI Sales OS v5.13.4

## Dashboard 整页虚线焦点框修复

- 删除 Dashboard 主内容滚动视口偶发显示的 Windows/WPF 默认黑色虚线焦点框。
- 不再在侧栏右侧和页头下方形成贯穿整页的十字虚线。
- Dashboard 外层滚动视口不再进入 Tab 顺序，键盘焦点会直接进入真正可操作的按钮、输入框和下拉框。
- 既有按钮、输入框、下拉框和侧栏导航焦点状态继续保留，兼容亮色与暗色主题。
- 新增原生回归门禁，防止整页默认焦点框重新进入 Dashboard。
