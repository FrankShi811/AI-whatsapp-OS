# AI Sales OS v5.18.11

## 邮件原格式预览与链接优化

- 邮件正文中的可点击链接现在会直接显示在消息气泡中（🔗 蓝色下划线，点击用系统浏览器打开），不再是无处可点的纯文本。
- 新增“查看原格式（表格/按钮/链接）”按钮：以网页方式完整还原邮件的 HTML 排版，表格、按钮、图片与链接均可正常显示和点击，内嵌图片自动映射到本地附件。
- 修复大邮箱同步附件时“邮件同步暂时不可用：后台 IMAP 会话正在重连”的问题：历史邮件补拉附件前先批量预检邮件结构，没有附件的邮件不再全量下载；单轮补拉数量受限，单次同步超时从 60 秒放宽到 180 秒。

## 发布边界

- 仅发布 Windows x64 简体中文安装包和 Velopack 自动更新资产。
- 不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新后继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本和最近 3 个回滚版本。
- macOS 构建继续暂停。
