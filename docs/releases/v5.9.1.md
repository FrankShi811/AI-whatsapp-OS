# AI Sales OS v5.9.1

## 分板块模型设置真正可见、可验证

- 商机智能顶部操作按钮现在显示该板块实际使用的 Provider、模型和推理深度，不再错误显示全域模型。
- 保存分板块模型后只更新必要的设置状态和商机智能路由提示，不再同步刷新全部业务页面。
- 七个可配置板块均通过独立模型持久化与解析回归；商机智能和 WhatsApp 的真实 AI 请求体也分别验证了不同模型与推理参数。

## 跨 WhatsApp 账号客户按统一记录处理

- Dashboard 今日行动简报不再生成“同一客户出现在多个 WhatsApp 账号，需要统一本轮跟进责任”的提醒。
- 同一客户跨账号出现属于正常情况；系统继续按统一客户身份共享客户资料、Customer Brain、消息历史与跟进上下文。

## 数据与发布边界

- 升级不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、消息、WhatsApp/邮箱账号、API Key、知识库、自动化或报告数据。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不更新本机正式程序；安装或更新继续创建或修复桌面快捷方式。
- macOS 正式发布继续暂停。
