# AI Sales OS v5.15.1

## 新电脑 Gmail 重新授权

- 邮箱账号资料和已同步历史仍可随本地数据工作区迁移，但 Gmail、Yahoo、iCloud 等平台的应用专用密码只保存在原电脑的 Windows 凭据管理器。
- 换电脑后若本机凭据缺失，邮件 Inbox 会明确显示“此电脑尚未保存凭据”；点击同步会直接打开原账号设置，要求重新填写应用专用密码并测试保存。
- 缺少本机凭据不再被误报为普通网络断线或后台重连，也不需要删除邮箱账号；重新授权后继续使用原有本地邮件历史。

## WhatsApp 跨电脑二维码恢复

- WhatsApp 加密会话缺少当前电脑的本机密钥时，不再被后台当成可直接恢复的有效会话。
- 程序会保留账号、聊天记录和客户关联，安全备份来自其他电脑的旧加密登录目录，再建立新的扫码会话。
- WhatsApp Inbox 会显示“此电脑需扫码”并继续等待 WhatsApp 返回的真实二维码；不生成占位二维码，也无需反复退出或删除账号。
- 旧会话损坏、密钥不匹配和跨电脑重新授权均改为页面内状态，不再弹出阻塞式恢复对话框。

## Windows 自动代理与网络适配

- 网络路由补齐 Windows 当前用户的手动代理、自动代理、PAC 和 WPAD 解析。
- Gmail IMAP / SMTP 与 WhatsApp 共用安全网络选择：先尝试系统识别的代理，再按既有规则回退直连。
- 自动代理解析、连接错误和界面提示均不会显示代理账号密码；一次 PAC 或代理失败不会永久标记账号失效。

## 数据与更新安全

- 新增本机凭据缺失、WhatsApp 跨电脑会话备份、后台连接资格及 Windows PAC/WPAD 回归测试。
- 升级不会覆盖客户、原始字段、消息、WhatsApp/邮箱账号资料、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或更新后继续创建或修复桌面快捷方式；更新缓存继续只保留当前、待安装新版本及最近 3 个回滚版本。
- 本版本只发布 GitHub Windows 中文安装包与 Velopack 自动更新资产，不直接修改本机正式程序；macOS 发布继续暂停。
