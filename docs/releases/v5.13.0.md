# AI Sales OS v5.13.0

## Customer Intelligence 跨渠道上下文层

- WhatsApp 与邮件 Inbox 的 Customer Intelligence 删除“公司”输入项；WhatsApp 同时删除营销同意与退订之间没有标签的来源空白框。
- 原“备注 / 最近情况”拆分为两部分：
  - “人工备注”只保存销售人员手动记录，不会再被最新聊天或邮件覆盖。
  - “AI 上下文总结”综合客户全部已保留的 WhatsApp 与邮件历史，提炼态度与兴趣、性格倾向、说话语气、沟通习惯、异议与顾虑、购买信号、当前关系和建议沟通方式。
- AI 上下文使用“客户列表 / Customer Brain”板块选择的 Provider、模型与推理深度。首次按时间顺序分批读取历史；后续新消息或人工备注变化时增量更新；输入未变化时复用本地结果。
- 每条进入 Customer Brain 的 AI 推断保留来源、证据和置信度；客户原文、销售人工备注和 AI 推断保持不同性质，不能互相冒充或覆盖。
- 客户智能分析的事实提取、商业判断、销售策略与报告生成新增人工备注和最新 AI 上下文作为依据因子，并继续区分客户事实、人工输入、AI 判断与销售建议。
- WhatsApp、邮件和客户智能分析使用手册已同步更新，并明确“刷新总结”会消耗 Token。

## 升级与发布边界

- 升级不覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或自动更新继续创建或修复桌面快捷方式。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
