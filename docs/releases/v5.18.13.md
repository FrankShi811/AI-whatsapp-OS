# AI Sales OS v5.18.13

## 邮件图片显示与 WhatsApp 标签同步

- 邮件中的图片现在可以直接显示：正文中的内嵌图片会以缩略图形式展示在邮件气泡中（点击“查看原格式”可看完整排版），不再显示 [image] 占位文本。
- 修复“查看原格式”预览中图片加载不出来的问题：本地附件图片通过 WebView2 虚拟主机映射加载，与邮件排版一同完整显示。
- WhatsApp 标签全新支持：
  - 手机 WhatsApp 上打的客户标签自动同步到 OS（连接后同步，存量标签请点“同步联系人与历史”拉取）；
  - 会话列表显示标签胶囊，工具栏可按标签筛选客户；
  - 打开会话点“🏷 标签”可添加/移除标签、新建/删除标签，实时同步回 WhatsApp 服务器，手机端同步可见。

## 发布边界

- 仅发布 Windows x64 简体中文安装包和 Velopack 自动更新资产。
- 不关闭、重启、安装或覆盖本机正式程序。
- 安装或更新后继续创建或修复桌面快捷方式。
- 更新缓存继续只保留当前、待安装新版本和最近 3 个回滚版本。
- macOS 构建继续暂停。
