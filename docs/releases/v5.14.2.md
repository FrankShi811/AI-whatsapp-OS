# AI Sales OS v5.14.2

## WhatsApp 首次连接二维码自愈

- 修复新电脑首次连接 WhatsApp 时可能长期停留在“连接中”却不显示二维码的问题。
- 在线兼容协议查询增加超时；网络受限或查询失败时自动使用安装包内置兼容协议。
- 二维码 35 秒未生成时自动重建连接，旧连接迟到事件不会污染新连接状态。
- 桌面端等待真实二维码或已连接结果；最终超时后安全结束本次任务并允许直接重试。
- 页面内显示准备、连接、自动重试及网络/防火墙提示，不再用阻塞弹窗掩盖连接状态。
- 页面切换期间收到的二维码会缓存在内存中，返回 WhatsApp Inbox 后自动恢复。
- 只绘制 WhatsApp 返回的真实二维码，不生成占位或伪造二维码。
- 新增在线查询超时、网络拒绝、无效响应、内置协议降级和隔离二维码链路测试。

## 数据与发布边界

- 升级不覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- 本版本仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序。
- 安装或更新继续创建或修复桌面快捷方式；更新缓存继续保留当前版本、待安装新版本及最近 3 个回滚版本。
- macOS 发布继续暂停。
