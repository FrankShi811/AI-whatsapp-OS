# AI Sales OS v5.12.0

## Dashboard 未读消息 AI 行动摘要

- “今日行动简报”会读取 WhatsApp Inbox 与邮件 Inbox 的真实未读原文，由 Dashboard 独立模型整理成可扫描的销售行动要点。
- 每个要点显示渠道、联系人、未读数量、最近时间、客户来意、重点摘要、建议下一步和优先级，并可直接打开对应 Inbox 查看完整原文。
- 摘要不会自动回复、自动标记已读、自动创建客户或修改 CRM；销售人员始终在查看原文后决定如何处理。
- 同一组未读消息复用本地缓存，切换板块和后台刷新不会重复消耗 Token；未读集合变化或点击“重新汇总”时才重新调用模型。
- Dashboard 可在“设置 → 板块模型与 Token 成本”中独立选择 Provider、模型及 API 已声明的推理深度。
- 模型未配置或暂时异常时显示安全的未读原文预览，不使用弹窗打断工作。

## 升级与发布边界

- 升级不覆盖客户、原始字段、消息、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或自动更新继续创建或修复桌面快捷方式。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
