# AI Sales OS v5.4.1

## 邮件会话新消息气泡

- 邮件 Inbox 左侧每个会话新增独立新邮件数量气泡，与 WhatsApp 会话列表保持一致。
- 未读会话同时使用浅色底纹和加粗客户名称，用户可以直接辨别哪位客户发来了新邮件。
- 单个会话超过 99 封未读时显示 `99+`，避免挤压客户名称、邮箱和时间。
- 进入具体邮件会话后，列表气泡即时消失，并把单调已读游标持久化到 SQLite。
- 切换板块、切换邮箱账号、页面重载或重新同步不会恢复已经读过的气泡；真正晚于已读游标的新邮件仍会正常计数。
- 全局左侧邮件 Inbox 气泡继续汇总全部已连接邮箱账号。

## 升级与发布边界

- 不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、邮箱账号、邮件历史、WhatsApp 账号、消息、API 配置、自动化、报告或知识库数据。
- 仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产；不安装或重启本机正式程序。
- macOS 发布继续暂停。
