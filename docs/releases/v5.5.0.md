# AI Sales OS v5.5.0

## 邮件销售工作台与 AI 写信

- 邮件 Inbox 的会话搜索框右侧新增“＋”入口。选择发件账号后可填写收件邮箱、主题和正文创建新邮件；选择既有会话仍进入回复模式，并携带最近客户来信的邮件线程引用。
- 右侧 Customer Intelligence 升级为跨渠道销售上下文工作区，展示 Lead Intelligence 分数、Customer Brain 数据覆盖、客户画像和下一步建议，同时保留人工维护统一 CRM 客户资料的能力。
- 新增 Email Sales Copilot，使用邮件 Inbox 独立配置的 Provider、模型和推理深度，根据销售人员的写信意图、当前草稿、CRM、Customer Brain、真实邮件历史和已批准知识生成新邮件或回复草稿。
- AI 产出包含主题、正文、上下文摘要、客户意向、风险、下一步和知识参考。点击“填入邮件”后仍需人工核对并手动发送；生成过程不会自动发送、创建邮件记录、修改 CRM 或作出价格、库存、交期与政策承诺。
- 全面审计并更新全局、WhatsApp Inbox、邮件 Inbox、客户智能分析和 API 设置引导，补充全账号后台同步、未读气泡、Agent 模式、新建邮件、AI 写信、Customer Brain 和 Token 消耗边界。

## 验证与数据安全

- 新增邮件 AI 独立模型路由、销售意图与真实上下文传递、结构化草稿校验、不发送安全边界、新建邮件 UI、客户智能侧栏和引导完整性回归。
- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、邮箱/WhatsApp 账号、消息、API Key、自动化、报告或知识库。
- 本版本仅发布 GitHub Windows 中文安装包与 Velopack 自动更新资产；macOS 继续暂停。
