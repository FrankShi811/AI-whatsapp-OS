# AI Sales OS v5.9.2

## 更新并重启改为一次点击

- 更新包在后台下载并校验完成后，点击左下角“更新并重启”会立即安装并自动重启，不再弹出 Yes/No 二次确认窗口。
- 版本更新历史窗口中的“安装更新并重启”保持相同的一键行为。
- 更新尚未准备完成时仍进入版本历史页面；只有安装状态异常、文件缺失或安装程序无法启动时才显示错误提示。

## 数据与发布边界

- 升级不覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户、消息、WhatsApp/邮箱账号、API Key、知识库、自动化或报告数据。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不更新本机正式程序；安装或更新继续创建或修复桌面快捷方式。
- macOS 正式发布继续暂停。
