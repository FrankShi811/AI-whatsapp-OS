# AI Sales OS v5.14.0

## WhatsApp 会话智能双向翻译

- 自动读取 Windows 当前界面语言作为本机语言，并仅依据所选会话中客户近期发来的有效文字识别客户主流语言。
- 会话顶部显示“本机语言 ⇄ 客户语言”、识别样本数与置信度，避免把销售人员自己的语言误判为客户语言。
- 点击“翻译最近消息”后，在原始消息下方显示译文；原始 WhatsApp 内容始终保留，不被译文覆盖。
- 使用本机语言撰写草稿后，可点击“译成客户语言”生成客户主流语言预览；必须先采用译文、再由用户手动点击发送，翻译不会自动联系客户。
- 语言识别结果与相同原文译文保存在本地缓存中，重复查看不重复消耗 Token；客户发来新内容或板块模型变化时会自动重新判断。
- 翻译统一使用“设置 → 板块模型与 Token 成本”中 WhatsApp Inbox 的独立模型配置，并提供内联加载、失败和恢复提示，不弹出阻塞式错误框。

## 可用性与验证

- 双语消息、长译文预览、按钮焦点、状态播报、亮色主题、暗色主题和 80% 界面缩放均已完成原生视觉验收。
- 新增原生回归测试，覆盖 Windows 本机语言解析、仅按客户来信识别主流语言、翻译缓存、原文不变以及草稿预览不自动发送。
- 更新 WhatsApp Inbox 新手引导，明确 Token 消耗、缓存和人工发送边界。

## 数据与发布边界

- 不覆盖客户、消息原文、WhatsApp/邮箱账号、API Key、知识库、自动化、报告、本地数据工作区或 SQLite 数据。
- Windows 安装或自动更新继续创建或修复桌面快捷方式，并仅保留当前、待更新版本及最近三个回滚版本的更新缓存。
- 仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不直接覆盖、关闭、重启或安装本机正式程序。
- macOS 构建继续暂停。
