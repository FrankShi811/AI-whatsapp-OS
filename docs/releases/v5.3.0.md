# AI Sales OS v5.3.0

## WhatsApp 群聊实时同步与安全展示

- 修复手机 WhatsApp 已显示新群消息、AI Sales OS 却完全不展示的问题：Bridge 接收范围新增 `@g.us` 群会话，不再在进入 SQLite 前丢弃群聊与群消息。
- 群聊以稳定群 JID 作为独立会话身份，支持历史包、实时消息、群名、最新消息、时间、未读数量、已读游标、媒体元数据和撤回状态的增量持久化；不会改写已有个人会话数据。
- 会话列表新增“群聊”标签；群消息气泡显示发送成员的 WhatsApp 名称，名称缺失时回退到成员号码或“群成员”。
- 群消息会计入 WhatsApp Inbox 和左侧导航的全账号未读气泡；打开群会话后使用与个人聊天相同的单调已读游标，旧历史或过期快照不能恢复已清除的未读数。
- 群聊采用只读安全模式并在会话头部明确说明：不绑定单一 CRM 客户，不进入 Lead Intelligence、Customer Brain 或 Customer Success Agent 自动回复，避免把不同群成员误归为一个客户或产生自动误发。
- 个人聊天发送、附件、回复、撤回、置顶、服务端消息 ID、客户目标校验及发送者手机多设备同步链路保持不变；群聊置顶仍在手机 WhatsApp 操作。
- 新增群 JID 路由、历史/实时摄取、成员署名、未读清除、SQLite 重启兼容、CRM/AI 隔离和完整桌面回归。

## 升级与数据安全

- 升级不会覆盖 `%LOCALAPPDATA%\WAFlow\waflow.db`、客户资料、WhatsApp 账号、消息、API 配置、邮件账号、自动化任务、Windows 凭据或知识库数据。
- 本版本仅发布 GitHub Windows 中文安装包和 Velopack 自动更新资产，不覆盖、关闭、重启或安装本机正式程序。
- macOS 构建、安装包与 Release 资产继续暂停。
